# Zuha Kaleem's Assignmetnt 1
This is a guide to help you run my assignment. 

## Getting Started 

### Step 1: Open my assignment in Codespace
1. Click the green **Code** button and switch to the **Codespaces** tab.  
2. Select **Create Codespace**.
3. Wait a few minutes for the environment to finish setting up.

### Step 2: Install requirements
1. Run the following in terminal: pip install -r requirements.txt
2. Then run this: pip install chromadb

### Step 3: Run my Assignment
1. Ten run this: streamlit run chat_with_pdf.py
2. On the popup that appears, click **“Open in Browser”** to view my assignment. 
   ⚠️ *If you miss the popup:*  
   - Press **Ctrl + C** in the terminal to stop the app.  
   - Rerun the command from step 1 — the popup should appear again.
3. A new browser tab will open, showing the interface of my assignment.
